# Guia Rápido do Sistema de Indicadores Estratégicos

Use este guia para as tarefas mais frequentes. Para regras, explicações e
solução de problemas, consulte o [manual completo](manual-do-sistema.md).

## Antes de começar

1. Entre no sistema com sua identificação corporativa.
2. Confira seu nome, perfil e escopo no cabeçalho.
3. Se essas informações estiverem incorretas, não faça lançamentos.

## Administrador

### Cadastrar um acesso

```text
Configurações → Acessos → Novo registro
→ informar matrícula, nome, perfil e escopo
→ Salvar acesso → conferir na Matriz de Cobertura
```

Para preenchedores, selecione o grupo DICOT, DILOT, SURCI ou SUCTF. Para o
Auditor CAIXA, informe também o período, protocolo, aprovador e justificativa da
concessão temporária.

### Preparar um ciclo de indicadores

```text
Configurações → conferir Indicadores → conferir Metas
→ configurar Prazos de Apuração → validar Matriz de Cobertura
```

### Gerar acompanhamentos de iniciativas

```text
Iniciativas Estratégicas → informar o ano
→ Gerar → filtrar os quatro trimestres e conferir
```

O sistema não duplica acompanhamentos existentes. Se o ano já tiver 1TRI,
2TRI e 3TRI, serão criados apenas os registros ausentes do 4TRI.

### Consultar pendências

```text
Homologação → indicadores pendentes
Homologação de Iniciativas → iniciativas pendentes
Auditoria → operações e acessos
```

## Unidade Apuradora — indicadores

```text
Lançamentos → filtrar → abrir o lançamento
→ preencher os dados → revisar os cálculos
→ informar observação → anexar evidência aplicável
→ Salvar rascunho → Enviar para homologação
```

Se o registro for devolvido:

```text
Lançamentos → filtrar Devolvido para ajuste → abrir
→ ler a observação da diretoria → corrigir
→ Salvar rascunho → Reenviar para homologação
```

## Unidade Apuradora — iniciativas

```text
Iniciativas Estratégicas → selecionar ano e trimestre → Filtrar
→ Abrir → atualizar status e Andamento da Unidade
→ atualizar Marcos, Próximos Passos e Frentes/Projetos/Ações
→ anexar evidência aplicável → Salvar rascunho
→ Enviar para homologação
```

O botão **Abrir** acessa o trimestre. O botão **Cadastro**, visível ao
administrador, altera o cadastro mestre da iniciativa.

## Diretoria Homologadora ou Consultor

### Indicadores

```text
Homologação → filtrar pendentes → abrir
→ conferir números, observação e evidências
→ registrar observação da diretoria
→ Homologar ou Devolver para ajuste
```

### Iniciativas

```text
Homologação de Iniciativas → Analisar
→ conferir andamento, itens e evidências
→ Homologar ou Devolver para ajuste
```

## Usuário da Companhia

```text
Resumo Executivo → aplicar os filtros
→ consultar cards, mapa de desempenho e gráficos
→ abrir o detalhe institucional quando disponível
```

Esse perfil é somente de consulta institucional.

## Auditor CAIXA

```text
Resumo Executivo / Visão Trimestral → consultar resultados
Lançamentos (consulta) → consultar lançamentos e documentos
Iniciativas Estratégicas → consultar acompanhamentos
Dossiê de Auditoria → consultar relatórios
Trilha de Auditoria → filtrar operações e acessos
```

O acesso é somente leitura e funciona apenas durante a concessão autorizada.

## Significado dos principais estados

| Estado | O que fazer |
|---|---|
| Não iniciado | Iniciar o preenchimento. |
| Em preenchimento / Rascunho | Completar, revisar e enviar. |
| Enviado para homologação | Aguardar a diretoria. |
| Devolvido para ajuste | Corrigir e reenviar. |
| Homologado | Registro aprovado e oficial. |
| Reaberto | Corrigir a nova versão e reenviar. |

## Se algo não aparecer

1. Limpe os filtros.
2. Confira ano, competência ou trimestre.
3. Confira perfil e escopo no cabeçalho.
4. Verifique se o cadastro ou prazo está ativo.
5. Peça ao administrador para consultar **Matriz de Cobertura** e **Acessos**.

## Ao terminar

1. Confirme a mensagem de sucesso da última operação.
2. Verifique se o status mudou como esperado.
3. Clique em **Sair**.
